# Expense Tracker Android App

A modern and user-friendly **Expense Tracker Android Application** developed using **Java** and **SQLite Database** as part of my **BCA 2nd Year – Semester 4 Android Programming Learning Journey**.
This project helps users manage their daily expenses efficiently by tracking spending records, calculating total expenses, and organizing financial data in a simple interface.

---

# Features

* Add Daily Expenses
* View Expense Records
* Delete Expenses
* Auto Total Expense Calculation
* SQLite Database Integration
* RecyclerView for Expense Listing
* User-Friendly UI
* Real-Time Data Updates
* Clean Material Design Interface

# Functionalities

## Add Expense

Users can:

* Enter expense title
* Enter amount
* Save expense to SQLite database

## View Expenses

Users can:

* View all expenses in RecyclerView
* Check total expense amount

## Delete Expense

* Long press on an expense item
* Expense gets deleted from database
* Total amount updates automatically

---

# Database

The application uses **SQLite Database** for storing expense records locally on the device.

### Example Fields

* Expense ID
* Expense Title
* Amount
* Date
* Category
